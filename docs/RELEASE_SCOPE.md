## 检查方法

对发布文本作人工审阅，并执行文件类型、大小、密钥格式、硬编码凭据、本机路径和嵌套 Git 检查；测试使用合成数据，不导入原工作区。自动规则不能证明不存在所有形式的敏感信息，尤其不能单凭文件名判断策略敏感性。
